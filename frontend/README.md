# Frontend

React application served by Vite. Use Node.js 24 (see `.nvmrc`) and npm.

From this directory:

```sh
npm ci
npm run dev
```

Open http://localhost:5173. The dev container installs dependencies automatically.

## Commands

- `npm run dev`: development server with React Fast Refresh.
- `npm run build`: production bundle in `dist/`.
- `npm run preview`: preview the production bundle at http://localhost:4173.
- `npm run lint`: check JavaScript, JSX, and React Hooks.
